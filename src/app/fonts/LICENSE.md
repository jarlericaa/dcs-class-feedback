# Fonts shipped with this application

## XCharter (subset)

`XCharter-Roman.woff2`, `XCharter-Bold.woff2`, `XCharter-Italic.woff2` are
Latin-subset WOFF2 conversions of the OpenType XCharter fonts distributed on
CTAN (<https://ctan.org/pkg/xcharter>), by Michael Sharpe, an extension of
Bitstream Charter.

These files are modified copies: they have been converted to WOFF2 and subset
to Latin-1, Latin Extended-A, general punctuation, currency, arrows and a small
set of geometric shapes.

Why this face: Charter was drawn for the low-resolution laser printers that
produced the departmental handouts, syllabi and posted notices this interface
is modelled on. It carries the authored-text register described in
[DESIGN.md](../../../DESIGN.md); interface chrome stays on the platform sans.
